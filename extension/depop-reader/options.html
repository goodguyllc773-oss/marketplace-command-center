MCC Depop Reader

Passes the Depop messages page you have open to Marketplace Command Center on this computer.

Clicks Depop's own "Refresh" button on the list so new messages show up — only on the list, and never while you're using the page.

Opens Depop's Offers tab, reads it for MCC, then goes back to Chat. Depop may clear its own "unread offers" marker when the tab is viewed — MCC alerts you instead.

Status

No reports yet.

How to use
  • Open depop.com/messages in a tab and leave it open.
  • Leave the conversation list showing — opening a conversation can mark it read on Depop.
  • If Chrome's Memory Saver is on, add depop.com to "Always keep these sites active".

It never opens conversations (that would mark them read), types, or sends anything on Depop, and never reads cookies or passwords. The only clicks it ever makes are the optional Refresh and Offers/Chat tabs above. It only talks to MCC on this PC.
